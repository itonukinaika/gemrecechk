# Gemini AI レセプト点検ツール gemrecechk

**gemrecechk** は、日本医師会ORCA管理機構の「WebORCA」からレセプトデータを抽出し、Googleの生成AI「Gemini」を用いて点検を行うWindows用ツールです。

## 特徴

- **純粋なAIによる点検:** 公開されている情報では、これまで存在しなかった「純粋にAIだけを用いてレセプトを点検する」ツールです。
- **プライバシーに配慮:** Geminiには氏名や生年月日などの個人情報は一切送信せず、病名と診療行為のリストのみを送信します。
- **クリーンな動作:** インストールは不要で、実行ファイル単体で動作します。デバッグログを有効に設定しない限り、データはメモリ上だけで処理され、PC内に個人情報を残しません。
- **圧倒的な低コスト:**
  - 日々の診療後に数十件程度の点検を行うのであれば、Gemini APIの無料枠内でも運用可能です。
  - 1ヶ月分まとめて点検する場合でも、有料契約で1件あたり1.5円程度ですので、小規模な診療所であれば、大幅なコストカットを実現できます。
- **高度なカスタマイズ性:** 日本語で記述できる「ユーザープロンプト」を編集することで、自施設の運用に合わせた点検内容の微調整が自由に行えます。

## クイックスタート

1. **APIキーの取得:** [Google AI Studio](https://aistudio.google.com/) 等からAPIキーを取得してください。
2. **設定:** アプリを起動し、「設定」からWebORCAのアドレス、ユーザー名、パスワード、および取得したGemini APIキーを入力します。
3. **プロンプト編集:** `gemprompt.txt` を開き、独自の点検ルールを日本語で記述します。（初回起動時に、記載例を入れて生成します）
4. **データ取得:** 「ORCAの受付リストを使用して患者一覧を所得」または「レセ電ファイルを用いて患者一覧を所得」を選択して点検を開始します。

## 便利な使い方
1. **レセプトを分割して点検できます:** 一度点検したレセプトは、再度点検操作をしても再送信されません。まずは国保だけ点検して、終わったら残りだけ点検するといったこともできます。途中でエラーが出て点検が中断しても、再度点検を開始すれば続きから点検できます。
2. **一覧印刷も便利です:** レセプト点検画面で、「国保」「社保」「後期」および、「不備が指摘されたものだけ」でフィルタリングができます。例えば、「国保」の「不備の指摘されたもの」でフィルタリングして、「一覧印刷」をしたりすると、他社様のレセプト点検ソフトウェアと類似した出力が得られます。
3. **画面上だけでも利用できます:** 所得した全レセプトを画面で確認することもできますので、ペーパーレスでの運用も可能です。
